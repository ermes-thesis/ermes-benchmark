# Ermes Benchmarks

This repository contains the benchmarking suite for the Ermes Framework.
The goal is to evaluate the performance of the framework and compare it against baseline executions.

The repository is organized into two main sections:

- [WASM](wasm_benchmark): Micro-benchmarks select the optimal WebAssembly runtime for Ermes.
- [Ermes](ermes_benchmark): End-to-end benchmarks running on a deployed Ermes infrastructure.
