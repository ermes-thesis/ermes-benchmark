## Calculating Net Execution Time

To get the **pure function execution time** (without WASM runtime overhead):

```
Net Execution Time = Total Execution Time - Overhead Time
```

Example for Wasmedge_AOT_NoOpts with PrimeNumbers:
1. Look up total time in `timing_PrimeNumbers_20251102_175545.json`
2. Look up overhead time in `timing_overheads_PrimeNumbers_20251102_175545.json`
3. Subtract overhead from total

Note: Native runtime has no overhead binaries (overhead is negligible).
